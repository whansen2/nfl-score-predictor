# Blitz – Local NFL LLM Agent

This folder contains **Blitz**, a lightweight, local AI assistant built to work alongside your NFL score predictor. It uses the **TBD model** to chat, predict, flag — all offline.

---

## Folder Structure

llm/
├── blitz.py                 # Main CLI for LLM tasks (chat, predict, etc.)
├── requirements.txt         # Only LLM-related dependencies
├── Makefile                 # Helper commands (make chat, make predict, etc.)
├── models/                  # Place GGUF model here (not tracked in Git)
│   └── TBD.gguf

---

## Getting Started

1. Create a virtual environment (recommended):

    make venv
    source nfl_env/bin/activate

2. Install LLM dependencies:

    make install

3. Download the TBD model:

    • Visit: TBD
    • Download: TBD.gguf
    • Move it into: llm/models/

Note: This file is ~TBD and not tracked by Git.

4. Generate predictions for Blitz to reference:

    make run

Note: Blitz uses data generated by your predictor. Make sure to run `make run` before using commands like `flag`.

## Usage

You can run Blitz from either inside the `llm/` directory or using top-level shortcuts from the project root.

From inside `llm/`:

    make chat          # Interactive Q&A about matchups
    make predict       # Run model + output predictions
    make flag          # Show upsets or close calls
    make recap         # Get summaries of each game
    make run           # Runs both flag and recap together

From the root of the project:

    make blitz-chat
    make blitz-predict
    make blitz-flag
    make blitz-recap
    make blitz-run

Tip: You can also run:

    make blitz-help

...to list all Blitz-related commands with descriptions and emojis.

    make install

---

## Model Safety & Trust

The model is downloaded from **TheBloke**, a verified Hugging Face publisher. It uses the **GGUF format**, which contains only weight data — no executable code. The file is loaded by `llama.cpp`, not executed.

---

## Repo Hygiene

- `.gitignore` excludes `llm/models/` and `.gguf` files
- `.dockerignore` avoids copying large weights into Docker images
